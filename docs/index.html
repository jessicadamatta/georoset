🪨 GeoRoset

Conversor open-source de convenções geológicas entre Leapfrog, Isatis.neo e Vulcan.

Como usar
  1. Selecione a aba correspondente ao tipo de dado
  2. Escolha o software de origem e o de destino
  3. Individual: insira os ângulos e clique em Converter
  4. Tabela: insira múltiplos valores ou cole um CSV
  5. Verifique o gráfico — os objetos devem se sobrepor
  6. Baixe os resultados em CSV
